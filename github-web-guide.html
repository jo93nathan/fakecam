Compiler FakeCam depuis GitHub Web

Aucune installation locale nécessaire : GitHub build le .deb à ta place.

1Pousse le projet sur ton repo 
cd ~/FakeCamTweak
git add .
git commit -m "FakeCam v3"
git push
Assure-toi que le fichier .github/workflows/build.yml est bien présent (il l’est déjà).
↓
2Ouvre ton repo sur github.com
Dans ton navigateur : https://github.com/TON_USER/fakecam
↓
3Clique sur l’onglet « Actions »
Il est en haut du repo, à côté de Code, Issues, Pull requests.
↓
4Dans la colonne de gauche, choisis « Build FakeCam »
C’est le nom du workflow qu’on a ajouté.
↓
5Lance le build
- Soit automatiquement après ton git push ;
- Soit clique sur Run workflow → Run workflow (branche main).
↓
6Attends la fin
Le run passe au ✅ vert quand c’est terminé (environ 1–2 min).
↓
7Télécharge l’artifact
Tout en bas de la page du run : Artifacts → fakecam-deb ↓
Décompresse le zip pour obtenir com.lemaso.fakecam_*.deb.
↓
8Installe sur l’iPhone 8
Envoie le .deb via AirDrop/SSH et installe-le avec Sileo ou Cydia.
Redémarre l’app Appareil photo : les boutons 🖼 et ⭕ apparaissent.
Problème ?
Si l’onglet Actions n’apparaît pas : le fichier build.yml n’est pas sur la branche par défaut.
Si le run est rouge : clique dessus puis sur l’étape Build package pour lire le log.
